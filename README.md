# Pixel Pomodoro

Personal pomodoro timer with pixel animations. Browser app, entirely local: no install, no build, no server.

## Usage

Open `index.html` in a browser.

- Ubuntu: run `xdg-open index.html` from this folder.
- macOS: `open index.html`. Windows: double-click the file.

Space starts and pauses the timer. The gear icon opens settings: timer lengths, scene (Miner, Campfire, Plant, Mountain), font, light/dark mode, sound, notifications and auto-start.

Settings and today's count are saved in your browser's localStorage, so they don't carry over to other browsers.
